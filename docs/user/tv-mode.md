# TV mode

TV mode is a full-screen layout for driving agents from across the room, on a large monitor or a TV, with a wireless keyboard, a gamepad mapped to keys, or speech-to-text software that types keystrokes. It works on web and desktop, locally or over a remote connection.

## Start

Open `/tv` on the device you want to use, or choose **Enter TV mode** in the command palette. TV mode is saved per device, so turning it on for the TV does not change your laptop.

The lobby lists your active threads, with the ones waiting on you (approvals, questions, failures) first, and shows your remaining subscription limits at the top.

| Key        | In the lobby                                   |
| ---------- | ---------------------------------------------- |
| Arrow keys | Move between threads                           |
| `Enter`    | Open the thread                                |
| `N`        | Start a new thread (pick a project, then type) |
| `U`        | Open Usage                                     |
| `+` / `-`  | Make everything larger or smaller              |
| `F`        | Toggle full screen                             |
| `Q`        | Exit TV mode                                   |

## In a thread

Threads open in the normal thread view, enlarged and without the sidebar, so messages, diffs, images, and PDFs look as they do elsewhere. Typing goes to the composer, so dictated text lands there without clicking first.

Press `Escape` to leave the composer, and `Escape` again to return to the lobby. The button on the left edge does the same with a mouse.

## Exit

Press `Q` in the lobby, use **Exit TV mode** at the bottom of the lobby, or choose **Exit TV mode** in the command palette.
